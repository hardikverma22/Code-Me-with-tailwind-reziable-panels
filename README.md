# CodeMe

A fast, free playground for HTML, CSS and JavaScript. Write code, see it live, share it with a link.

## Features
- Live preview in a sandboxed iframe, with a built-in console (logs and errors)
- CodeMirror 6 editors with Emmet and Prettier formatting
- Resizable panels and a mobile layout
- Share: your code is compressed into the link itself, no account needed
- Everything autosaves to your browser

## Develop
```bash
npm install
npm run dev     # http://localhost:5173
npm test        # unit tests
npm run lint
npm run build
```

Stack: Vite, React 19, TypeScript, Tailwind CSS 4, Zustand, CodeMirror 6.
